# Never Heroes

Site do RPG Never Heroes (HTML, CSS e JavaScript puros, sem dependências).

## Estrutura

```
index.html
css/style.css
js/main.js
```

## Como hospedar no GitHub Pages

1. Crie um repositório novo no GitHub (por exemplo, `never-heroes`).
2. Envie **o conteúdo desta pasta** (não a pasta em si) para o repositório. O arquivo `index.html` precisa ficar na raiz.
3. No repositório, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e salve.
5. Aguarde um ou dois minutos. O site fica em `https://SEU-USUARIO.github.io/never-heroes/`.

As fontes (Cinzel e Cormorant Garamond) vêm do Google Fonts, então o site precisa de internet para exibi-las corretamente.
